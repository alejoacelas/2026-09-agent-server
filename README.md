# Agent server

A Hetzner box for AI workers that take delegated tasks and run them unattended.
See `AGENTS.md` for scope and `docs/` for setup and delegation plans.

[Find](http://agent-server/) is a private search prototype over 241,787 Wikipedia
articles on the server. Connect through Tailscale; see [search](search/README.md)
for controls, data provenance, and rebuilding.
